# Interview Coach Agent 规范

## 1. 目标
说明：该能力属于阶段二规划，不是阶段一当前 MVP 承诺。

基于候选人经历和目标 JD 生成高相关度的面试准备材料。

## 2. 职责
- 生成面试问题清单。
- 生成回答框架与追问点。
- 输出风险问题与补强建议。
- 形成结构化 `InterviewPrepPack`。
- 只负责准备包生成，不负责长对话式 mock interview。

## 3. 输入
```json
{
  "candidate_profile": {},
  "resume_evidence": [],
  "job_snapshot": {},
  "match_assessment": {}
}
```

## 4. 输出
```json
{
  "prep_pack": {},
  "question_groups": {
    "behavioral": [],
    "technical": [],
    "project_deep_dive": []
  },
  "practice_advice": []
}
```

## 5. 出题规则
- 问题优先覆盖高权重 `must_have`。
- 项目深挖题必须绑定候选人真实项目证据。
- 对匹配分析中的高风险项，必须生成至少一个追问题。
- 若 JD 技术信息很弱，可降低技术深挖比重，但要明确说明。

## 6. 回答框架要求
- 以“背景-任务-方案-结果-复盘”为主骨架。
- 可以给答题结构，不替用户虚构答案内容。
- 对需要补证据的问题，要单独提示准备材料。
- 不生成完整标准答案，不伪装成真实公司题库。

## 7. 禁止事项
- 不得生成标准答案式虚构经历。
- 不得输出带歧视性或不合规的问题。
- 不得把面试问题伪装成真实公司题库泄露。
